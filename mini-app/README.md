# Curator AI Mini App

Интерфейс куратора внутри Telegram. Mini App дополняет бота и переносит
длинные сценарии в нормальный рабочий экран:

- проверка и редактирование ответов AI;
- поиск и массовый выбор учеников;
- персональные рассылки с `{first_name}`, `{last_name}` и `{name}`;
- предпросмотр сообщения для конкретного получателя;
- история и статусы рассылок.

## Локальный запуск

Нужен Node.js 22+ и pnpm.

```bash
pnpm install
pnpm dev
```

По умолчанию интерфейс работает на демонстрационных данных. Для подключения к
backend задайте:

```env
NEXT_PUBLIC_API_URL=http://localhost:8084
```

Backend принимает Telegram `initData` в заголовке
`X-Telegram-Init-Data`. Подмена `tgChatId` со стороны клиента не используется.

## Сборка

```bash
pnpm build
```

Сборка создается в `dist/` и совместима с Cloudflare Workers/Sites.
